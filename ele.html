Electronic Components Library

Resistor

Type: Passive Component

Function: Limits the flow of electric current in a circuit.

Unit: Ohm (Ω)

Resistors are used to control current and divide voltage.
Applications: LED circuits, voltage dividers and pull-up circuits.
Common values: 220Ω, 330Ω, 1kΩ, 10kΩ.
🔋

Capacitor

Type: Passive Component

Function: Stores electrical energy in an electric field.

Unit: Farad (F)

Capacitors store and release electrical charge.
Applications: Filtering, coupling, timing and power supply circuits.
Types: Ceramic, electrolytic and film capacitors.
💡

Diode

Type: Semiconductor Component

Function: Allows current to flow mainly in one direction.

Example: 1N4007

A diode conducts when forward biased and blocks current when reverse biased, within its ratings.
Applications: Rectifiers, reverse-polarity protection and signal circuits.
🔌

Transistor

Type: Active Component

Function: Works as an electronic switch or amplifier.

Example: BC547, 2N2222

Transistors control current using an input signal.
Applications: Amplifiers, switching circuits and digital electronics.
Types: BJT, MOSFET and JFET.
🔲

Integrated Circuit (IC)

Type: Semiconductor Component

Function: Contains multiple electronic components in a single chip.

Example: 555 Timer IC

ICs combine transistors, resistors and other elements.
Applications: Computers, amplifiers, timers and communication systems.
🟩

Arduino UNO

Type: Microcontroller Board

Function: Controls electronic devices using programmed instructions.

Controller: ATmega328P (classic UNO R3)

Arduino is an open-source electronics prototyping platform.
Applications: Robotics, automation, smart home and IoT projects.
Programming: Arduino IDE using C/C++.
🍓

Raspberry Pi

Type: Single Board Computer

Function: A compact computer capable of running an operating system.

Programming: Python, C and more.

Raspberry Pi is a small computer used for software and hardware projects.
Applications: AI, robotics, IoT, computer vision and automation.
It provides GPIO pins for connecting electronic components.
📟

ESP32

Type: Microcontroller Board

Function: Provides processing, Wi-Fi and Bluetooth connectivity.

Programming: Arduino IDE, ESP-IDF.

ESP32 is widely used in connected electronics projects.
Applications: IoT, wireless monitoring and smart devices.
Features vary by ESP32 model.
🌡️

Temperature Sensor

Type: Sensor

Function: Measures temperature.

Example: LM35

Temperature sensors convert temperature into an electrical signal.
Applications: Weather stations, industrial monitoring and automatic cooling systems.
📡

Ultrasonic Sensor

Type: Distance Sensor

Function: Measures distance using ultrasonic sound waves.

Example: HC-SR04

It calculates distance using the time taken by an ultrasonic pulse to return.
Applications: Obstacle detection, robotics and parking systems.
💡

LDR Sensor

Type: Light Sensor

Function: Changes resistance according to light intensity.

Full Form: Light Dependent Resistor

LDR resistance generally decreases when light intensity increases.
Applications: Automatic street lights, light detection and brightness control.
🌀

Inductor

Type: Passive Component

Function: Stores energy in a magnetic field.

Unit: Henry (H)

An inductor opposes changes in current through it.
Applications: Filters, DC-DC converters and power supplies.
